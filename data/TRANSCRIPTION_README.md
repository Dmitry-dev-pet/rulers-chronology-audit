# Расшифровка плаката (этап 2)

Оцифрованы **106 строк**, вручную по увеличенным фрагментам оригинальной фотографии без OCR: 53 слева и 53 справа.

- `poster-transcription.tsv` — семь полей с буквальным чтением (годы правления, имя, пояснение, годы жизни, уверенность в чтении)
- `section-markers.md` — заголовки, строки о столицах, названия династий
- `research/initial-audit.md` (в корне проекта) — отдельный исследовательский разбор: **не смешивать** с расшифровкой

**Это не исторически верифицированный список.** Не исправлять плакат «вслепую» по внешним источникам в этом файле: вести исправленные данные в отдельном реестре. Уверенность в чтении ≠ уверенность в правильности фактов. Некоторые мелкие символы и ~ требуют повторной визуальной сверки по оригиналу.
