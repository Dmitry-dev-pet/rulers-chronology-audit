# GitHub Actions: советская хронология

Workflow: `.github/workflows/soviet-audit.yml` — **Soviet chronology audit**.

## Что выполняется

В публичном репозитории сборка запускается после push в main, pull request в main,
вручную через Run workflow и при событии `public` (смена видимости репозитория).
Пока репозиторий приватный, job намеренно **skipped**, чтобы не расходовать закрытую
квоту. Это не успешная проверка; первый настоящий запуск нужно проверить отдельно.

Обычный GitHub-hosted runner `ubuntu-24.04`, максимум пять минут. Python — из образа,
без pip-зависимостей и вызовов языковых моделей. Нет self-hosted runner, доступа к
Mac, Google Drive, пользовательским секретам или записи в репозиторий. Токен имеет
только `contents: read`; checkout не сохраняет его. Actions закреплены полными SHA.

Скрипт проверяет JSON, уникальность идентификаторов, календарную корректность дат,
явно обратные интервалы, ссылки на PC-источники и неизменность исходной расшифровки
106 строк. Пересечения сроков, коллегиальное управление, временное замещение и
неполные даты разрешены: они не исправляются искусственно.

**CI не проверяет истинность исторических утверждений и не скачивает веб-источники.**
HTTP-доступность ссылки тоже не была бы доказательством её содержания. Первичные
документы проверяются исследователем, а известные пробелы переносятся в отчёт.

## Результат

В успешном запуске Actions откройте артефакт **soviet-chronology-report**. После
распаковки `index.html` показывает три параллельные колонки и отдельные спорные
эпизоды; на телефоне колонки располагаются последовательно.

Артефакт содержит HTML, четыре CSV, chronology.json, sources.json, validation.json,
README и SHA256SUMS. Контрольные суммы входных данных и commit SHA позволяют
определить точную версию отчёта. Оригинальная фотография и её закрытые Drive-ссылки
не включаются. Артефакты хранятся 14 дней, исходные исследования остаются в Git.
Это сборка артефакта, **не развёртывание GitHub Pages**.

Локальная проверка (не обязательна для пользователя):

```sh
python3 -m unittest discover -s tests -v
python3 scripts/soviet_audit.py --revision local-review
```

Проверка 14 unit-тестов проведена при подготовке workflow. Эти тесты используют
минимальные синтетические данные; реальный набор проверяет шаг сборки в Actions.
Исходная транскрипция зафиксирована Git blob SHA в скрипте: её редакторское изменение
требует отдельной проверки происхождения, а не автоматического обновления эталона.
