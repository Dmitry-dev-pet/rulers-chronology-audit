# Биографическая полнота: проверка без автоматического домысливания

В рабочей базе 83 уникальные личности, включая монархов, министров, соправителей, советских чиновников и участников коллективных органов. Для 35 из них после этого этапа есть отдельные даты рождения (часть только до года), ещё 48 пока без источниковой даты рождения.

**Важное ограничение:** первоначальная задача касалась 69 лиц, оставшихся после первой партии из 14. В этом проходе исследовано 21 из них; остальные **48 ещё не проверены**, а не объявлены автоматически проверенными.

Обзор готовит команда `python3 -m scripts.biography_coverage`: она читает канонические JSON и выдаёт список неопределённостей для каждого человека. Код не связывается с интернетом, не присваивает национальность по фамилии и не изменяет исторические факты. В `database.html` непроверенные даты явно остаются «Не исследовано».

Проверенные конкретные случаи: [вторая партия биографий](../research/biographies-second-pass.md), [оценки центров власти](../research/factual-power-second-pass.md).

Исторический источник подтверждает определённую датировку, но не доказательство единоличной власти. Для недатированных рождений историческое сравнение возраста остаётся недоступным.
