# Wikidata P8 — оставшиеся должности: от 122 утверждений к 80 карточкам QID

**Исследовательский срез: 13 октября 2026.** Продолжение [Issue #46](https://github.com/Dmitry-dev-pet/rulers-chronology-audit/issues/46), после объединённого [P7 PR #53](https://github.com/Dmitry-dev-pet/rulers-chronology-audit/pull/53). Никакие новые исторические сроки правления, фактическая власть, родственные связи, этничность, границы или должностные соответствия **не добавляются**.

## Сколько данных осталось

Три независимых отчёта одного [живого аудита P7 #38381243622](https://github.com/Dmitry-dev-pet/rulers-chronology-audit/actions/runs/38381243622) сопоставлены **по ID конкретного утверждения Wikidata P39**, а не по совпадению фамилий:

| Показатель | Результат |
| --- | ---: |
| Все утверждения P39 | 214 |
| Утверждения, классифицированные P2/P3, кроме deprecated | 91 |
| Deprecated, не принимаемые в работу | 1 |
| Ещё не классифицированные P39 | **122** |
| Различные QID этих 122 утверждений | **80** |
| Люди, которым принадлежат 122 утверждения | **47** |
| QID с одной записью | **56** |
| QID с двумя и более записями | **24** |
| Утверждения с явной ссылкой на источник в P39 | **26 из 122** |
| Утверждения с обоими квалификаторами P580/P582 | **88 из 122** |

Воспроизводимый [срез всех 80 групп CSV](../research/wikidata/p8-unmapped-qid-groups-2026-10-13.csv) содержит **QID, число утверждений, разных людей, утверждений со ссылками и двух датированных границ**. Это не 80 различных юридически доказанных должностей: QID иногда описывает чрезмерно широкий титул или должность иного исторического периода.

Распределение повторяемости: 56 QID по одной записи, 10 по две, 11 по три, 2 по четыре и 1 QID пять раз. Лидер частот — [Q27491113](https://www.wikidata.org/wiki/Q27491113), *член Всероссийского учредительного собрания* (5 утверждений без явных ссылок и обеих временных границ в нашем P39-срезе). **Член собрания ≠ правитель.**

## Очередь исследования (ручные приоритеты, а не вывод из частот)

В [списке ручной проверки](../design/wikidata/p8-manual-review-queue-v1.json) помечены **8 первоочередных QID, 1 проблемное соответствие и 7 следующих**. Остальные 64 пока не проверялись, но не признаны неправильными.

| Блок | Примеры QID и причина |
| --- | --- |
| Регентство | [Q477406](https://www.wikidata.org/wiki/Q477406): три утверждения, все три имеют ссылки. Нельзя приравнять регента к царю/императору или утверждать автоматическое фактическое лидерство |
| Московский княжеский титул | [Q12370487](https://www.wikidata.org/wiki/Q12370487): три утверждения, в том числе лица разных столетий. Требуется отделять великого князя Московского от великого князя всея Руси |
| Царский титул | [Q12370489](https://www.wikidata.org/wiki/Q12370489): царь всея Руси. Исторические титулы 1547 и императорский с 1721 — разные юридические контексты |
| Португалия | [Q58800860](https://www.wikidata.org/wiki/Q58800860): монарх Португалии; отдельно проверять короля-супруга, регента и суверенную королеву |
| Советские правительства | [Q134407102](https://www.wikidata.org/wiki/Q134407102) — заместитель председателя СНК СССР; [Q134373912](https://www.wikidata.org/wiki/Q134373912) — заместитель председателя Совета министров СССР. Реорганизация 1946 года и ранг заместителя не допускают механического слияния. Отдельно [Q5452917](https://www.wikidata.org/wiki/Q5452917) — первый заместитель; [Q56919889](https://www.wikidata.org/wiki/Q56919889) — председатель СНК **РСФСР** |
| Подозрительное соответствие | [Q842386](https://www.wikidata.org/wiki/Q842386): Wikidata описывает премьер-министра современной России, но использует QID для Керенского, Львова и Трепова. **Статус карантина** до исторической проверки — не отождествлять эти должности |

Первый следующий небольшой PR целесообразно посвятить **регентству и московским/царским титулам** (Q477406, Q12370487, Q12370489), второй — **историческому разделению советских правительственных должностей**. Перед изменением реестра нужно получить независимые источники для конкретного лица, юридического контекста и дат. Исследовательская очередь сама не переносит ни одного P39 в историческую базу.

## Доказательство происхождения и повторяемость

Исходный P7-артефакт `wikidata-p7-live-2026-10-13` хранится GitHub Actions 14 дней. SHA-256 трёх первоначальных отчётов:

- `latest.json`: `6402b5ff018c343c420b5d149f07e7fe6f43c59e861396f45ca563ffe87daa59`
- `offices.json`: `8ed86302f43d8e33a7a5ea40ef6a4c10e3a4b437d5aa9588add43b0a0c9165fe`
- `jurisdictions.json`: `083b4c7cfbf18fa30da948b28a21be0b579dbf75b524bb0941e81e55b29096ae`

Скрипт `scripts/wikidata_p39_backlog.py` проверяет фиксированные 80 групп и три переданных исходных отчёта. Он отклоняет несовпадающие ID утверждений, различия оригинальных квалификаторов/ссылок, конфликт классификаторов P2/P3, deprecated и неверную аттестацию. Он **не вызывает сетевые API** и не записывает данные канона.

Проверка без сети:

```bash
python3 -m unittest tests.test_wikidata_p39_backlog -v
python3 -m scripts.wikidata_p39_backlog
```

При наличии трёх распакованных файлов *одного* Actions-run:

```bash
python3 -m scripts.wikidata_p39_backlog \
  --latest /path/to/latest.json \
  --offices /path/to/offices.json \
  --jurisdictions /path/to/jurisdictions.json
```

Программа выводит точные QID, у которых увеличилось/уменьшилось число утверждений или изменилась источниковая полнота. Сохранённый CSV — **групповая проекция**; индивидуальные ID утверждений и полный текст квалификаторов содержатся в оригинальном Actions-артефакте до окончания срока хранения. CSV остаётся воспроизводимым сравнительным базисом, но не претендует на замену полного исходного архива.

**Без изменений:** 83 канонические российские персоны, 27 отдельных международных персон, все сроки/свидетельства, P4-короны, 150 provenance, оригинал плаката, SQLite и публичная Pages-версия. CI проверяет структуру и повторяемость, а не историческую истинность.
