## Где живут данные

- Приватная папка проекта в Google Drive: rulers-chronology-audit.

- Редактируемый канон проекта: data/atlas/ в GitHub. SQLite/JSON/SPA — производные файлы. Ни исходные бинарные файлы, ни приватные URL Drive нельзя включать в публикацию.

## Проверка файлов (без импорта в канон)

~~~sh
# Файлы вручную скопированы или скачаны из личного Drive на локальную машину.
# Для CSV/TSV достаточно Python 3. Для .dta: pip install pandas;
# для .xlsx: pip install openpyxl. Эти пакеты не нужны сайту.
mkdir -p dist/external-datasets
python3 -m scripts.inspect_external_datasets archigos /path/to/Archigos_4.1_stata14.dta > dist/external-datasets/archigos.inspect.json
python3 -m scripts.inspect_external_datasets plad /path/to/PLAD.xlsx > dist/external-datasets/plad.inspect.json
python3 -m unittest discover -s tests -p test_inspect_external_datasets.py -v
~~~

Скрипт возвращает исходные колонки, число строк, количество пустых значений, повторы значений *кандидатных* идентификаторов и SHA-256. Никаких исходных строк, биографий, этничности, родственных связей или секретов в JSON-отчёте нет. Повтор leadid допустим при нескольких сроках; повтор *не равен* дубликату личности.

## Следующий исследовательский шаг

1. Загрузить оба оригинальных файла и codebook в соответствующие папки Drive, проверить SHA-256 после обратного скачивания.
2. Снять реальную схему колонок и различить идентификатор личности, срока и государства. Для Archigos учитывать leadid/obsid; для PLAD использовать только *явный* Archigos ID, если он есть в данной версии.
3. Составить **draft crosswalk** с source + version + native_id, не объединять имена по сходству и не подменять разные политические контексты одним государством.
4. Сравнить случаи СССР/России 1953, 1991 и России 2008–2012 с юридическими сроками и опубликованными интерпретациями; несовпадения хранить как альтернативные оценки с источниками.
5. Только после проверки лицензий, даты, методики и соответствий выпускать разрешённый публичный JSON-срез. Не превращать этничность, место рождения, гражданство и династию в одно поле.

Исторические факты и существующие данные в этом этапе **не изменяются**; никакая сборка не объявляет историческую истинность подтверждённой.
