# Wikidata P4: юридические короны Богемии и Венгрии в v2

**Статус:** экспериментальный, источниковый слой, 12 октября 2026 года.
Это **реальные датированные записи в одноразовой проекции SQLite v2**, а не
массовая автоматическая миграция из Wikidata и не изменение исторического
канона v1/публичного сайта.

## Зачем нужен этот шаг

В европейском пилоте 1762–1800 уже присутствуют 40 персональных ролей и 3
учреждения. Кандидаты Wikidata Q45341328 (король/королева Богемии) и
Q6412254 (король/королева Венгрии) отражают **две разные юридические
должности/короны**, а не два дополнительных человека и не два
тождественных территории государства. Это важно для составной монархии
Габсбургов и должности выборного императора Священной Римской империи.

В P4 заведены два контекста `ctx-hab-crown-bohemia` и
`ctx-hab-crown-hungary`, каждый связан с `ctx-world-hab` только как
`related_not_equivalent`. По ним добавлены восемь отдельных записей
о юридических коронах:

| Лицо / world-ID | Богемская корона | Венгерская корона | Ограничение |
| --- | --- | --- | --- |
| Мария Терезия / `hab-maria` | 1740–1780 | 1740–1780 | Срез атласа с 1762; война за наследство и коронации требуют отдельного источника |
| Иосиф II / `hre-joseph` | 1780–1790 | 1780–1790 | Не венчался венгерской короной, отдельная историческая оговорка |
| Леопольд II / `hab-leopold` | 1790–1792 | 1790–1792 | Коронации: Венгрия 1790, Богемия 1791; **коронация ≠ начало срока** |
| Франц II / `hab-francis2` | с 1792 | с 1792 | В исследовании обрезается в 1800, не датой конца правления |

Это *юридические* записи, не оценка личной действенной власти.
Один человек с двумя коронами остаётся **одним человеком**. В пилоте
взаимосвязь должностей не преобразуется автоматически в личную унию,
карту политического контроля, национальность, династию или новый
суверенный современный State.

### Календарь, доказательства и цензурирование

Для каждой строки [curated-crown-roles-v1.json](../design/wikidata/curated-crown-roles-v1.json)
фиксирует конкретный Wikidata QID лица, **ID утверждения P39**, QID
должности, revision исходной карточки, точное исходное значение P580/P582
со стилем и точностью, музейный источник пилота, интерпретационную
оговорку, исходные годы. Число и формат даты в Wikidata сохраняется как
первичное содержимое **внешнего утверждения**, а не переводится
автоматически в однозначно установленный день коронации/вступления.

Для показа P4 использует годы пересечения исходного срока с окном
**1762–1800 включительно**. При отсечении начала 1740 года для Марии
Терезии поле `start_date_json` у периода оставлено NULL; при отсечении
конца 1835 года у Франца II `end_date_json` тоже NULL. Год 1800 — лишь
конец выборки, **не отречение Франца II**. В 1790 году проекция
показывает четырёх кандидатов (по две короны для Иосифа II и Леопольда
II) — это **не четыре одновременно правивших лица и не доказательство
совместной власти в определённый день**.

Музейные справки подтверждают исторический контекст, но мы **не
проводили самостоятельную экспертизу всех первичных актов и календарных
дат**. Verification: `reference_checked`; confidence:
`not_assessed`; `historical_truth_verified_by_ci=false`.

Источники:
- [Die Welt der Habsburger — Maria Theresa](https://www.habsburger.net/en/persons/habsburg-emperor/maria-theresa)
- [Die Welt der Habsburger — Joseph II](https://www.habsburger.net/en/persons/habsburg-emperor/joseph-ii)
- [Die Welt der Habsburger — Leopold II и коронации](https://www.habsburger.net/en/chapter/short-term-emperor-leopold-ii-imperial-throne)
- [Die Welt der Habsburger — Franz II (I)](https://www.habsburger.net/en/persons/habsburg-emperor/franz-ii-i)
- Дополнительно — Wikidata P39 Q45341328 и Q6412254, ID конкретного утверждения и ревизия карточки в curated JSON.

## Что реально собирается

[atlas_v2_wikidata_roles.py](../scripts/atlas_v2_wikidata_roles.py) создаёт
**одноразовую** in-memory SQLite v1 + экспериментальную схему v2,
импортирует существующие 40 мировых ролей и 3 учреждения, добавляет
[схему P4](../schemas/atlas_v2_wikidata_crowns.sql) и восемь новых
`v2_roles`. В каждом случае есть отдельный `v2_periods`,
`v2_assertions`, **две ссылки на источники** (музей из пилота +
конкретное утверждение Wikidata), исходный JSON в
`v2_wikidata_crown_claims`, а также типизированная запись
`v2_wikidata_crown_contexts`. В общей view
`v2_timeline_year_candidates` новые строки помечены отдельным
`origin_layer='wikidata-curated'`, а не выдаются за исходный пилот.

`v2_wikidata_crown_year_candidates` — выборка **годовых кандидатов**.
SQLite оставляет `user_version=1`, исходные 83 личности, 150
строк provenance, штатные данные v1 и 43 старых world-импорта.
Обратной записи в `data/atlas`, original photo, `atlas.sqlite`
или Pages **нет**.

## Команды

Из корня репозитория, Python 3.11+, стандартная библиотека:

```bash
python3 -m unittest tests.test_schema_v2_wikidata_roles -v
python3 -m scripts.atlas_v2_wikidata_roles --year 1790
python3 -m scripts.atlas_v2_wikidata_roles \
  --wikidata-report reports/wikidata/latest.json \
  --json-output reports/wikidata/curated-crowns.json \
  --markdown-output reports/wikidata/curated-crowns.md \
  --sqlite-output reports/wikidata/atlas-v2-curated-crowns.sqlite
```

Перед указанным последним вызовом необходимо отдельно получить
`latest.json` командой `python3 -m scripts.wikidata_sync --discover`.
В живом отчёте P4 находит ожидаемый P39 statement ID/QID и проверяет
P580/P582, не подменяя локальные reviewed даты внешними изменениями.
При расхождении сохраняет `source_changed_review_required` для
ручной сверки, без автоматического переписывания истории.

Еженедельная GitHub Action сохраняет JSON, Markdown и одноразовую
SQLite в исследовательском артефакте. Вручную разрешённый report PR
включает **только текстовые отчёты**, не SQLite и не изменение
исторических справок. Файлы исследовательского артефакта не входят в
публичный Pages allowlist.

## Что дальше

После проверки этих восьми записей можно отдельно рассматривать
остальные **юридические** виды должностей из Wikidata (например,
королевство Пруссия, разные государства Франции, регентство Португалии),
не делая из каждого P39 автоматически «главного правителя».
Коллективные органы, фактическая власть и географический контроль
требуют собственных источников и отдельных типов.
