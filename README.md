## Содержание проекта

- [data/poster-transcription.tsv](data/poster-transcription.tsv) — буквальная ручная расшифровка **106 строк** (53 в левой колонке, 53 в правой), включая исходные ошибки.
- [data/section-markers.md](data/section-markers.md) — названия династий, служебные строки и подписи столиц.
- [research/initial-audit.md](research/initial-audit.md) — предварительный разбор 23 исторических утверждений.
- [research/source-index.md](research/source-index.md) — 25 стартовых ссылок на исторические источники; для научной сверки требуется повторная проверка каждого.
- [data/claim-register.csv](data/claim-register.csv) — реестр спорных утверждений.
- [docs/context.md](docs/context.md) — решение о хранилище и контекст обсуждения.
- [NEXT_STEPS.md](NEXT_STEPS.md) — дальнейшая построчная верификация и нормализованная хронология.
- [scripts/verify_original_photo.py](scripts/verify_original_photo.py) — сверка SHA-256 локальной копии при необходимости.

## Предварительная оценка

Главная проблема плаката — смешение **формальных монархов, регентов, номинальных правителей и де-факто лидеров**, без указания статуса. Отдельные даты и утверждения ошибочны; яркий пример — Симеон Бекбулатович (на плакате 1574–1576, обычно датируют номинальное правление 1575–1576). Кроме того, схема столиц не отражает политическую раздробленность.

**Расшифровка фото завершена предварительно, но независимая проверка всех 106 строк по историческим источникам ещё не завершена.** Предварительные выводы не следует считать полностью проверенной академической хронологией.
